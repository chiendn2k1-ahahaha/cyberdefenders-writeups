CyberDefenders writeups

Writeup tiếng Việt cho các lab Blue Team trên CyberDefenders: phân tích lưu lượng mạng (network forensics), bộ nhớ (memory forensics), máy trạm (endpoint forensics), threat intel và mã độc.

Mỗi bài đi theo từng bước điều tra, kèm ảnh chụp kết quả công cụ thật như Wireshark/tshark, Volatility, VirusTotal. Bài chỉ hướng dẫn nơi tìm đáp án, không ghi đáp án.

Danh sách writeup

  • Babble Loader - CyberDefenders writeup (Malware Analysis, Insane). Lần theo một loader x64 nhiều tầng bằng x64dbg: giải chuỗi XOR, API hashing và syscall trực tiếp, kiểm tra GPU chống sandbox, shellcode đếm tiến trình, rồi một bộ nạp .NET mã nguồn mở chạy payload sau khi vô hiệu AMSI.
  • BlindSentry - CyberDefenders writeup (Threat Hunting, Insane). Lần theo một cuộc tấn công nhiều giai đoạn từ web server Linux sang file server Windows và AWS, bằng log nginx, Volatility, Sysmon, Kerberos, CloudTrail và giải mã traffic Cobalt Strike.
  • Boomer - Lazarus Group - CyberDefenders writeup (Endpoint Forensics, Insane). Điều tra memory dump của một máy trạm Windows bị lừa qua "phỏng vấn xin việc" trên ứng dụng họp trực tuyến, bằng MemProcFS, registry, lịch sử Edge, timeline NTFS, $LogFile và một payload giấu trong Windows Event Log.
  • Zerologon - CyberDefenders writeup (Endpoint Forensics, Hard). Truy vết chuỗi tấn công từ một máy trạm phòng tài chính tới Domain Controller qua Sysmon, Security, System log và USN Journal.
  • BRabbit - CyberDefenders writeup (Threat Intel, Medium). Dựng lại chuỗi tấn công của ransomware Bad Rabbit, từ email lừa đảo tới persistence bằng scheduled task và sửa MBR, bằng sandbox và MITRE ATT&CK.
  • MBuchus - CyberDefenders writeup (Threat Intel, Medium). Dựng lại chiến dịch malvertising nhiều giai đoạn bằng OSINT, VirusTotal và crt.sh, từ trang web giả tới loader và hạ tầng của kẻ tấn công.
  • Trickbot - WIZARD SPIDER - CyberDefenders writeup (Threat Intel, Medium). Dùng báo cáo sandbox trên VirusTotal để phân tích một mẫu Trickbot: cách nó gọi WMI, tiến trình bị chèn mã, file thả vào ProgramData, khóa Run và hạ tầng C2 của file thứ cấp.
  • 3CX Supply Chain - CyberDefenders writeup (Threat Intel, Easy). Dựng lại vụ tấn công chuỗi cung ứng 3CX năm 2023 qua file MSI và các DLL bị cài mã độc, xác định TTP và nhóm tấn công.
  • DanaBot - CyberDefenders writeup (Network Forensics, Easy). Phân tích lưu lượng mạng để tìm đường xâm nhập ban đầu của DanaBot, từ file JavaScript giả hóa đơn tới DLL giai đoạn hai, và trích IOC.
  • FakeGPT - CyberDefenders writeup (Malware Analysis, Easy). Đọc mã nguồn một extension Chrome giả mạo ChatGPT để tìm cách nó né môi trường phân tích, đánh cắp thông tin đăng nhập và gửi dữ liệu ra ngoài qua thẻ ảnh (img).
  • GrabThePhisher - CyberDefenders writeup (Threat Intel, Easy). Đọc mã nguồn một phishing kit tiền điện tử để tìm cách kit lấy seed phrase của nạn nhân, kênh gửi dữ liệu ra ngoài và dấu vết người viết kit.
  • IcedID - CyberDefenders writeup (Threat Intel, Easy). Dùng VirusTotal và Malpedia để lần theo chuỗi phát tán IcedID, từ file Excel chứa macro Excel 4.0 tới payload DLL đội lốt ảnh GIF và nhóm tấn công đứng sau.
  • Lespion - CyberDefenders writeup (Threat Intel, Easy). Điều tra nghi vấn nội gián bắt đầu từ một tài khoản GitHub, tìm secret bị lộ trong lịch sử commit, liên kết các tài khoản mạng xã hội và xác định địa điểm qua ảnh.
  • Lockdown - CyberDefenders writeup (Network Forensics, Easy). Dựng lại cuộc xâm nhập nhiều giai đoạn vào một máy chủ web IIS từ PCAP, memory dump và file mã độc, gồm dò quét, web shell, reverse shell, persistence và C2.
  • Oski - CyberDefenders writeup (Threat Intel, Easy). Đọc báo cáo sandbox của một mẫu Stealc trên VirusTotal và Tria.ge để tìm thời điểm tạo, máy chủ C2, thư viện được tải, khóa giải mã chuỗi và hành vi tự xóa.
  • PsExec Hunt - CyberDefenders writeup (Network Forensics, Easy). Phân tích lưu lượng SMB trong một file PCAP để dựng lại cách PsExec được dùng để di chuyển ngang giữa các máy trạm.
  • Red Stealer - CyberDefenders writeup (Threat Intel, Easy). Dựng hồ sơ một mẫu infostealer từ VirusTotal, MalwareBazaar và ThreatFox để lấy IOC, hạ tầng C2, kỹ thuật MITRE ATT&CK và cơ chế leo quyền.
  • RedLine - CyberDefenders writeup (Endpoint Forensics, Easy). Phân tích memory dump của một máy trạm bằng Volatility 3 để tìm tiến trình lạ trong thư mục Temp, vùng nhớ chứa file PE, ứng dụng VPN và hạ tầng C2.
  • Reveal - CyberDefenders writeup (Endpoint Forensics, Easy). Dựng lại chuỗi tấn công từ memory dump Windows bằng Volatility 3: PowerShell chạy ẩn, kết nối share WebDAV và chạy DLL bằng rundll32 trực tiếp từ máy ở xa.
  • Web Investigation - CyberDefenders writeup (Network Forensics, Easy). Phân tích lưu lượng HTTP tới một web server PHP/MySQL để lần theo SQL injection, việc lấy dữ liệu khách hàng, đăng nhập trang quản trị và web shell được tải lên.
  • XLMRat - CyberDefenders writeup (Network Forensics, Easy). Lần theo chuỗi lây nhiễm XLMRat từ file pcap, giải rối script tải về, phân tích cách nạp .NET assembly trong bộ nhớ và process hollowing vào một tiện ích .NET hợp lệ.
  • Yellow RAT - CyberDefenders writeup (Threat Intel, Easy). Từ một hash mẫu, dùng VirusTotal và trang threat của Red Canary để gọi tên cụm mối đe dọa, lấy metadata của file và máy chủ C2.
